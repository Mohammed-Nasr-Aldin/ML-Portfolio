## 📂 Repository Structure

- index.html : Main semantic HTML structure
- styles.css : Custom styling, dark mode blueprint theme, and responsive layouts
- script.js : Interactive mobile menu, scroll reveal animations, and modal controllers
- resume.pdf : Professional resume (CV)
- credit-score-slides.pdf : Capstone project presentation slide deck
- certificate.jpeg : Verified STP Machine Learning Track completion certificate

---

## 🚀 Key Features & Highlights
- **Minimalist Flow Design**: Clean vertical rhythm without decorative clutter or heavy cards.
- **Responsive Navigation**: Smooth mobile menu with smooth-scroll motion and outside-click auto-close.
- **Mathematical Rendering**: Real-time formula integration using KaTeX ($IQR = Q_3 - Q_1$, Binary Cross-Entropy $\mathcal{L}_{\text{BCE}}$, and $F_1\text{-score}$).
- **Interactive Modals**: Direct in-browser previews for the resume PDF and certificate zoom view.
- **Featured Capstone**: Embedded PDF slide deck and deployment link for the Credit Score Prediction System.
